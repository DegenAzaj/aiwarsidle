Poniżej masz **6-miesięczną roadmapę Live Ops** po soft launchu.
Założenie: MVP działa, PvP usage ≥ 40%, D7 ≥ 12%.

Cel:

* zwiększyć retencję D30
* podnieść ARPDAU
* zbudować MRR (sub + pass)
* wprowadzić whale layer stopniowo

# MIESIĄC 1 — Stabilizacja + PvP Upgrade

### Cel:

Podbić zaangażowanie PvP i sprawdzić elastyczność ekonomii.

## Tydzień 1–2

* 3 przeciwników (easy/medium/hard)
* Zróżnicowane nagrody
* Log ataków
* Revenge button

## Tydzień 3–4

* PvP streak bonus
* Mały event rankingowy (bez nowej waluty)
* A/B test: reward PvP ×1.2 vs ×1.5

### KPI focus:

* PvP usage
* średnia liczba walk / user / dzień
* ARPDAU
